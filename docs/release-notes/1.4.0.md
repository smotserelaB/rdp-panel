What's new in 1.4.0

- Alt accounts, much more:
  - - and + buttons next to every number (choose the step: 1, 10, 100, 1,000 or 10,000).
  - The mouse wheel no longer changes a number by accident; it scrolls the list.
  - Link a session to an alt: you see if the session is online and a button takes you to it.
  - A goal per item with a progress line, and a message when you reach it.
  - History: the panel saves your numbers every day. See a chart per item and what changed today, this week and this month.
  - Search, sort (name, kind or most of an item) and collapse a card to make the list shorter.
  - A note per alt and the time it was last updated.
  - Export and import all alt data as CSV, and a backup or restore (zip) that includes the hive pictures, history and session links.
- A switch "Sound on / off" in the bar under the panel turns all sounds off at once.
- Ctrl+K opens a search window: sessions, pages, alt accounts and a few actions.
- Fix: a session no longer breaks when the panel is started hidden or minimised.
