What's new in 1.7.0

- A new page "Discord" with everything about the messages:
  - Choose which kinds of messages are sent: drops, problems (a PC does not respond), high CPU/RAM, frozen sessions.
  - A second webhook for important messages, with a mention (a role, a person, @here or @everyone), for example for a phone alert.
  - One reminder when a problem lasts longer than N minutes.
  - Bundling: when many sessions fail within a few seconds you get one message with the list.
  - The daily report: choose the time and the days. A weekly report (the last 7 days, compared with the 7 before) on a day and time of your choice.
  - Own webhook for the reports, and for the bot an own channel for commands and for the reports.
  - Change the text of the messages yourself with fields like {session} and {reason}, with a preview.
  - Test buttons for every kind of message and a list of the last messages that were sent, with the result.
- Per session: an own Discord webhook and an own bot channel (in the session settings).
