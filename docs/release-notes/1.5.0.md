What's new in 1.5.0

- New page "Health" (in the list on the left, with a number when something needs attention): what is wrong right now in plain language, with a button to fix it (reconnect, turn on a PC with Wake-on-LAN, open Settings, update).
- A "Getting started" card on the overview: add a session, connect, set up Discord. It goes away by itself when the three steps are done (or click Hide).
- Duplicate a session (menu on its tile).
- Edit several sessions at once: the button "Edit several…" above the tiles.
- Profiles can switch by themselves on a schedule (Profiles, button Schedule…), for example office hours on weekdays.
- Settings can be exported to a file and imported again, for example on a new PC (without passwords and tokens). See Settings.
- The Daily summary now shows how long each session was connected yesterday.
- Shortcuts: Ctrl+N add a session, Ctrl+F search the sessions, F5 reconnect the selected one, Ctrl+M sound on/off, Ctrl+Shift+C compact view, Ctrl+L log, Ctrl+H Health.
