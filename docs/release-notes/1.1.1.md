What's new in 1.1.1

- The Daily summary now only shows the sessions that are on your screens (the active profile). A line at the bottom tells you how many are hidden by the profile.
- The daily report in Discord still reports every session, but sessions hidden by the profile have their own heading, so they do not look like problems.
- New: this "What's new" window appears once after an update.
- The text of a release on GitHub now comes from the release notes in the project, so the update window shows what really changed.
- README and manual brought up to date.
