What's new in 1.2.0

- New rules for automatic Discord messages (Settings, under the Discord bot):
  - Pause all automatic messages with one tick, for maintenance.
  - Quiet hours: choose a time window and whether nothing is sent, or only drops and PCs that stop responding.
  - Maximum messages per hour: above the limit the messages wait, and you get one short summary afterwards.
- The status of the Discord bot on the Settings page now updates by itself and shows since when it has that status.
- Webhook link and bot token: a Show / Hide button and a Clear button.
- The daily report is not affected by quiet hours and the limit (only by Pause).
